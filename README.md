# CIMS-InventoryManagement
CIMS-InventoryManagement — ปรับปรุงระบบ Stock จากการแยกฐานข้อมูลและโปรแกรม .exe สู่ระบบบริหาร Stock แบบรวมศูนย์ รองรับ Dynamic Barcode, Configurable Max/Min, Forecast &amp; Order Import, PR Scan, Multi-Warehouse, Product Control, Access Control, Audit Log และ Reporting โดยลดการพึ่งพาการแก้ไข Code เมื่อมีการเปลี่ยนแปลงข้อมูลหรือรูปแบบการใช้งาน.
